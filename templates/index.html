❓ 使用教程

个性化主题、三种加课方式、周次切换、串门看课表，以及怎么把它变成手机 / 电脑上的「App」。 关掉以后随时点右上角的「❓ 使用教程」都能再打开。

1个性化主题

点页面右上角的「⚙️ 切换主题」按钮，可以在两种风格之间自由切换：

  • 清爽毛玻璃：默认主题，浅色流体渐变背景 + 半透明玻璃卡片（橙 × 蓝）。
  • 终末地工业风：深灰黑底 + 细密工业网格，荧光黄 / 工业橙作强调色， 直角切角卡片，字体换成硬朗的等宽字体，按钮和边框都带高亮线条。

选择会记在这台设备的浏览器里（localStorage）：刷新页面、下次再打开都还是上次的风格； 换设备、换浏览器或清理浏览器数据后会回到默认的清爽毛玻璃。

2点格子加课（最快）

  1. 在课表里找到空白格子（第几节 × 星期几），点一下。
  2. 依次填写：课程名 → 开始节次 / 结束节次（单节课两个选一样，连堂课选 1 和 2）→ 地点（可以留空）→ 周数（直接回车就是 1-16 周）。
  3. 填完自动保存，格子里马上出现课程卡片；卡片右上角的 ✏️ 可以修改，× 可以删除。

3AI 文本批量加课

在「批量粘贴添加课程」里一次粘贴多门课（一行一门），AI 会自动识别星期、节次和周数。

周一上午1-2节高数
周三下午5-6节英语 @外语楼B203
周五 1-16单周 晚上9-10节 选修

节次规则：上午 1~4 节、下午 5~8 节、晚上 9~11 节，所以「下午第二节」= 第 6 节；写成「1-2节」会自动合并成一张跨两节的卡片。

4截图识别

  1. 在「上传课表截图一键解析」里选一张截图。超长截图也没关系：网页会先自动压缩成宽 1200px 的 JPEG 再上传，识别更准。
  2. 等 10~20 秒，页面下方会出现「识别结果确认」表格。
  3. 核对每一门课：识别错的行点 × 删掉，填错的地方直接改，最后点「确认保存」才真正写进课表。

5切换周次 & 串门看课表

  • 切换周次：拖动「当前周次」滑块（1~20 周）。打开页面会自动停在按开学日期算出的本周；勾选「显示所有周次」就不过滤，所有课程都显示。
  • 串门：点「🚪 去看『同学A』的课表」按钮，打开的是对方的只读课表，那边没有任何修改入口；看完点「回我的课表」就回来。
  • 分享：「只读分享链接」发给同学最安全，对方只能看；「专属免密链接」等于你的密码，别随手发给只想看看的同学。

6换头像

点身份栏左边的小头像就能选图片（2MB 以内，JPG / PNG / GIF / WebP），上传完立刻生效，不用刷新页面。

7添加到手机主屏幕（像 App 一样用）

小提示：添加时最好用你的「专属免密链接」（/?u=你的分享码），这样点开图标就是你的身份，不用再找链接。

📱 iPhone / iPad（Safari）
用 Safari 打开网页 → 点底部中间的「分享」按钮 → 在列表里找到「添加到主屏幕」→ 改个名字（比如「我的课表」）→ 点「添加」。
🤖 安卓（Chrome / Edge）
点右上角「⋮」菜单 → 「添加到主屏幕」或「安装应用」→ 确认。也可以直接点网页弹出的「安装」提示。
💬 在微信 / QQ 里打开的同学
先点右上角「…」→「在浏览器打开」，再按上面两步操作。微信内置浏览器不能直接添加。

8安装到电脑桌面

🪟 Windows / 🍎 Mac · Chrome
地址栏右侧出现「安装」图标（⊕ 或小显示器）时点它 → 「安装」；没有图标就点「⋮」→「保存并分享」→「创建快捷方式」，并勾选「在窗口中打开」。
🪟 Windows · Edge
点右上角「…」→「应用」→「将此站点作为应用安装」；也可以点地址栏里的「应用可用」图标。
🍎 Mac · Safari 17 以上
菜单栏「文件」→「添加到程序坞」，之后从程序坞点开，没有地址栏，和 App 一样。

安装出来的窗口本质还是这个网页：断网时打不开，数据也仍然存在这台服务器上。
